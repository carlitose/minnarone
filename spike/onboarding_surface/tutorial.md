# Human-only tutorial sketch

1. Copy the shadow config template and keep `send.mode: shadow`.
2. Record broadcaster consent before any future live run.
3. Select a profile and verify every model SHA-256/revision.
4. For Italian audio use the English VoxCeleb speaker model at dimension 512.
5. Treat `--check` as config validation; run the lazy VLM model smoke separately.
6. Follow the operator guide for soul/facts, tools, smokes and TUI.

This intentionally small sketch represents the docs-only surface. It explains
five safety/runtime hazards but cannot enforce a conversational preview gate or
validate retention/disclosure choices.
