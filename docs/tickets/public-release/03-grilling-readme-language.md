# Decidere la lingua del README per il pubblico

## Parent Spec

[public-release-wayfinder.md](../../specs/public-release-wayfinder.md)

## Type

grilling

## Outcome

Decisione registrata: il README pubblico resta in italiano, passa all'inglese,
o diventa bilingue (es. README inglese + README.it.md). Se serve traduzione,
nasce un ticket task derivato.

## Acceptance Criteria

- [ ] L'utente ha scelto tra: solo italiano / solo inglese / bilingue.
- [ ] La decisione è registrata nella mappa (`Decisions So Far`).
- [ ] Se serve traduzione, esiste un ticket task con scope chiaro (solo README,
      non i docs operativi).

## Blocked By

- None - can start immediately.

## Frontier

Il README è la prima cosa che un visitatore vede: cambiare lingua dopo il flip
è possibile ma la prima impressione conta. Decisione veloce, solo umana.

## Work Plan

1. Porre la domanda all'utente con le tre opzioni e trade-off (pubblico
   raggiungibile vs sforzo di manutenzione doppia).
2. Registrare la risposta nella mappa.
3. Creare l'eventuale ticket di traduzione.

## Evidence to Capture

- Risposta esplicita dell'utente.

## Out of Scope

- Traduzione dei docs operativi (`docs/*.md`) e dei docs interni.
